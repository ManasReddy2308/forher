KUSUMA BIRTHDAY WEBSITE
========================

Files:
- index.html  -> complete website structure
- style.css   -> all visual styling and animations
- script.js   -> navigation, petals, sparkles, transitions and flower shower
- photos/     -> put your five real photos here

To use your own photos:
1. Add these files to the photos folder:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
2. Open index.html in your browser.

Flow:
Home -> Message -> Cake / Make a Wish -> Memories / flower shower -> Final love gesture

The visual design intentionally follows the supplied reference:
- midnight blue / purple / pink palette
- handwritten script typography
- cherry-blossom / petal atmosphere
- parchment birthday letter
- warm candle + cake scene
- polaroid memory cards
- sunset mountain ending
- glowing heart "I Love You So Much"

You can change the name/text directly inside index.html.
